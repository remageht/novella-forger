# novella-forger

Истории людей → фантастические новеллы. События в метафоры, имена по событию.

## Использование в Antigravity (Gemini)

1. Открой эту папку в Antigravity
2. В чате: `@novella-forger вот история: ...`
3. Или положи историю в `stories/input/имя.md` и попроси обработать

## Структура

- `.agents/skills/novella-forger/SKILL.md` — главный промпт-скилл
- `GEMINI.md` — always_on правило
- `stories/input/` — исходные истории
- `stories/output/` — готовые новеллы
