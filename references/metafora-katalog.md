# Каталог метафор: событие → фантастика

Правила переноса:
1. Хронология реальных событий сохраняется 1в1. Меняется только обертка.
2. Эмоциональный вес сцены в новелле = весу события в реальности.
3. Одно реальное событие = одна сцена (или одна ступень пути).
4. Никаких реальных топонимов, дат и имен.

| Реальное событие | Что сохранить | Метафоры по жанрам |
|---|---|---|
| Расставание, развод | обрыв связи, дележ общего | культивация: раскол парного ядра, души на разные пики; исекай: распределение по разным мирам; постап: общее убежище рушится, маршруты расходятся; индустрия: совместный конвейер встает; магия: ковен развязывает узел |
| Переезд, эмиграция | страх неизвестного + надежда | исекай: призыв через Врата, печать принятия; постап: караван уходит через Пустошь; культивация: переход в чужую секту без рекомендаций; индустрия: перевод на другую плавильню |
| Болезнь, депрессия | угасание сил, изоляция | культивация: утечка ци, застой меридианов; постап: цепь заражения, карантин; магия: гаснущая искра, проклятие тишины; индустрия: отравление маной на смене |
| Бедность, долги | постоянное давление, стыд | культивация: дань секте, долг дхармы; постап: счетчик воды на нуле; индустрия: кабала нормы выработки, заложенный инструмент |
| Тяжелая рутина | стирание личности, однообразие | индустрия: смена у плавильни, одинаковые артефакты; культивация: годы на заднем дворе секты; постап: ремонт генератора ценой сна |
| Поддержка, спасение | тепло, долг благодарности | передача пилюли прорыва; проводник через Пустошь; место в цеху; укрытие в убежище; свеча в ночи |
| Предательство | доверие превращается в удар | культивация: удар в спину на трибуляции, кража дхармы; исекай: попутчик сдает координаты Врат; индустрия: напарник подставляет под выдворение; постап: свой открыл шлюз рейдерам |
| Потеря близкого | пустота, но память движет | постап: мемориал у стены убежища; культивация: дух-хранитель в ядре; магия: свеча, которую нельзя задувать |
| Новая любовь | второе дыхание | культивация: парные ядра резонируют; магия: две искры сплетаются; постап: два маршрута совпали |
| Рождение ребенка | новая ответственность | росток сквозь бетон; пробуждение новой души; первый росток на пепелище |
| Учеба, экзамены | проверка на прочность | культивация: испытание внешней секты, трибуляция; индустрия: допуск к станку высшего ранга; исекай: Акт Адаптации |
| Увольнение, изгнание | обрыв корней | индустрия: клеймо выдворенного из цеха; культивация: изгнание из секты; исекай: отзыв печати принятия |
| Конфликт с родителями | разрыв поколений | культивация: запретный путь вместо пути клана; постап: уйти из убежища вопреки Смотрителю |
| Одиночество | тишина вокруг | исекай: чужой город без единой знакомой нити; постап: молчащее радио; магия: погасший очаг |
| Выздоровление, перелом | возвращение сил | культивация: прорыв ступени после застоя; постап: генератор запущен; магия: искра разгорается |
| Творчество, призвание | свет сквозь рутину | индустрия: собственный артефакт вопреки регламенту; магия: новая формула света |
| Выгорание | пустой резерв | индустрия: мана-резерв на нуле, смена без сменщика; культивация: выжженная земля в ядре |
| Несправедливый начальник | безличное давление | индустрия: Надзиратель, для которого ты строка отчета; культивация: старейшина, раздающий ресурсы по родству |
| Возвращение домой | узнавание себя | исекай: обратные Врата; постап: старый маршрут, теперь безопасен |
| Свадьба, союз | соединение | культивация: соединение ядер при свидетелях; магия: большой ритуал свечей |
| Измена | удар изнутри | разрыв парного ядра изнутри; развязанный узел без предупреждения |
| Долгая дорога, скитания | трансформация в пути | исекай: караван из мира в мир; постап: Пустошь учит выживать |
| Естественная смерть старика | тихий итог, эстафета | культивация: старейшина растворяется в свете, оставляя технику; магия: свеча догорела до конца |
| Первая работа | вход во взрослый мир | индустрия: первый день у конвейера; исекай: первая печать в гильдии; культивация: первый зал внешней секты |
