# Имена по событию

Формула: **[Суть поступка + ранг/образ жанра]**.
Реальные имена запрещены — даже измененные. Читатель должен угадывать роль без расшифровки.

## Железные правила

1. Имя отражает ПОСТУПОК в переломный момент, а не «характер вообще».
2. Один персонаж — одно имя на всю новеллу.
3. Имя должно звучать в стиле жанра и произноситься вслух без спотыкания.
4. Система безлична (Надзиратель Плавильни №7), предатель — конкретен (Отступник Парного Пика).
5. Ребенок получает имя-росток: Росток, Малая Искра, Первый Шаг.

## Банк по ролям

| Роль в реальной истории | Примеры имен |
|---|---|
| Мать, забота, дом | Хранительница Очага, Теплая Рука, Мать Хлеба |
| Отец-опора, наставник | Старший Кузнец, Наставник Первой Ступени, Смотритель Огня |
| Друг-проводник | Проводница Врат, Попутчик Каравана, Брат по Смене |
| Любимый, любимая | Парное Ядро, Вторая Искра, Спутник Маршрута |
| Бывший, разрыв | Отступник Парного Пика, Развязанный Узел, Прошедший Мимо |
| Предатель | Сдавший Координаты, Тот-Кто-Отвернулся, Крадущий Дхарму |
| Начальник-давитель | Надзиратель Плавильни №7, Старейшина Дани, Требующий Норму |
| Конкурент | Претендент на Пик, Быстрейший у Конвейера |
| Спаситель в беде | Пилюля в Ночь, Поднявший Тебя, Передавший Уголь |
| Ребенок | Росток, Малая Искра, Первый Шаг |
| Враг-система без лица | Протокол, Счетчик, Регламент Ранга |
| Мудрый старик | Догоревшая Свеча, Хранитель Архива, Старейшина Тихих Вод |

## Проверка

Прочитай имя и спроси: «роль ясна без объяснений?» Если нет — переименуй.

## Запрещено

- Паспортные имена и их «замаскированные» версии (Мария → Мари, Дима → Дим).
- Уменьшительные формы (Леночка, Сашка).
- Клички, понятные только автору истории — имя должно читаться чужим человеком.
