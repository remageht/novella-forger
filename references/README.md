# Справочники Хрониста

Материалы для генерации новелл: терминология, тропы, стиль имен по жанрам.
Сервер подкладывает их в промпт автоматически (см. `server/gemini.ts`), а Antigravity-агент
использует при ручной генерации и правке текстов.

| Файл | Когда подключается |
|---|---|
| [metafora-katalog.md](metafora-katalog.md) | всегда |
| [imena.md](imena.md) | всегда |
| [kultivacia.md](kultivacia.md) | жанр: культивация |
| [isekai.md](isekai.md) | жанр: исекай / трансмиграция / переселение душ |
| [postapokalipsis.md](postapokalipsis.md) | жанр: постапокалипсис |
| [mago-industria.md](mago-industria.md) | жанр: маго-индустриализация |
| [magiya.md](magiya.md) | жанр: магия |

При жанре «авто» подключаются все жанровые файлы — модель сама выбирает доминант + подслой.

## Как это работает

- Файлы читаются при каждом запросе генерации — правки применяются без перезапуска сервера.
- Материалы — источник вдохновения, не шаблон. Модель комбинирует тропы под конкретную историю.

## Как добавить материал

1. Дополни существующий файл или создай новый `.md` в этой папке.
2. Новый жанр: добавь пункт в маппинг `genreRefFiles` в `server/gemini.ts` и в `GENRE_OPTIONS` в `web/src/types.ts`.
3. Закоммить — всё.
