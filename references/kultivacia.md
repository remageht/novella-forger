# Жанр: культивация

Мир, где личная сила растет ступенями через дисциплину, секты и испытания.
Идеален для историй про: долгий рост, предательство учителя, годы рутины, прорывы после застоя.

## Лестница ступеней (образец)

1. Закалка Тела
2. Открытие Меридианов
3. Формирование Ядра
4. Золотое Ядро
5. Ступень Души
6. Пик (полубессмертие)

## Устройство мира

- Секты: внешняя (новички) → внутренняя (ядро) → старейшины → глава.
- Ресурсы: пилюли, дхарма, техники, мана-кристаллы, платформы для трибуляций.
- Деньги и долги: духо-камни, ежесезонная дань секте.
- Экзамены: раз в сезон на Платформе Горного Испытания.

## Тропы

- Прорыв после застоя — событие выбивает человека вперед после долгих лет.
- Трибуляция — публичное испытание, где решается судьба.
- Удар в спину на трибуляции — предательство.
- Утечка ци, застой меридианов — болезнь, депрессия, выгорание.
- Пилюля прорыва — помощь близкого в трудный момент.
- Задний двор секты — рутинная, стирающая работа.
- Старейшина, раздающий ресурсы по родству — несправедливый начальник.
- Дух-хранитель в ядре — память о потерянном близком.

## Стиль имен

- Секты: Секта Парного Пика, Павильон Семи Плавилен, Обитель Тихих Вод.
- Техники: «Ладонь Долгого Двора», «Шаг Через Пустошь».
- Люди: титул + образ поступка (см. `imena.md`).

## Запрещено

- Реальные имена, топонимы, даты.
- Сухие числа-ступени — лучше образ: «третий зал внешней секты».
